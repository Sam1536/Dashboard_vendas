
# 📊 Dashboard de Vendas | Power BI

Dashboard interativo de vendas com visão do desempenho comercial: faturamento, lucro, quantidade vendida e margem, comparados ao ano anterior, além do acompanhamento das devoluções por produto, marca, loja e região.

## ✨ Recursos

- Comparação com o ano anterior (YoY) e com o mês anterior (MoM)
- Filtros por ano, período, país, continente e marca
- Navegação por botões entre as páginas
- Tooltips personalizados com o Top 5 de produtos
- Mapas, árvore de decomposição e parâmetro de campos

## 🛠️ Tecnologias

Power BI Desktop · DAX · Power Query

## 🚀 Como abrir

Baixe o arquivo `.pbix` e abra no **Power BI Desktop**. A navegação começa pela **Capa**.
